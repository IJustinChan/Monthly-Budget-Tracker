# Personal Project

## Project Overview
This application is a *budget app* that will help the user keep track of their income and expenses for a single month. I am interested in this project because as a university student, managing money and keeping track of expenses is very important in order to avoid overspending and ensure I can meet my needs. By making this budget program, it will make it easier for me to **manage** my money and **analyze** my finances. This budget application can be **used by anyone**, but it will mostly be targeted towards *university students* who need to keep a closer watch on their finances. University students often have multiple sources of income, such as scholarships, parents' support, student loans etc. and several expenses such as tuition, housing, food,  etc., so having an app that helps them manage all that information in one place will be very useful to them.

This budget app will allow users to add multiple incomes and expenses along with information about that money such as type, amount, date, and other useful information. They will be able to calculate total money earned or spent, and the app will also create graphs to visualize the data. Moreover, this app will let the user explore "what-if" scenarios and see how that would impact their finances. For example, they could analyze what happens if rent increases by $100 this month, they need to pay $2000 in tuition for summer courses and they receive few thousand dollars in scholarships. This would help the user assess their financial situation and help inform them on decision making.

## User Stories
* As a user, I want to be able to add an income into my budget and specify the amount, source of that income, date income was received, and if its taxable or not. I also want to add an expense into my budget and specify information about that expense such as type of expense, amount and date.
* As a user, I want to be able to view all the incomes and expenses that has been added in a single month. I want to be able to see the amount of money, type and date added for each income and expense. I also want to be able to see a summary of the entire budget for the month. 
* As a user, I want to be able to test different "what-if" scenarios by adding additional income and expenses. These new financial information should not appear in my actual budget.
* As a user, I want to be able to calculate total income and expense for the month. I also want to be able to see the net income for the month.
* As a user, I want to be able to delete a income or expense from my budget.
* As a user, I want to be able to update a income or expense from my budget. I can change all or some of the information about the income or expense.
* As a user, when I select the Exit button to stop the application, I want to have the option to save my budget to a file and I can also choose not to.
* As a user, when I begin the application, I want to have the option to load my budget from a file or not
