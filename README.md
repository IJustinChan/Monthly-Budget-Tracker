# Personal Project

## Project Overview
This application is a *budget app* that will help the user keep track of their income and expenses. I am interested in this project because as a university student, managing money and keeping track of expenses is very important in order to avoid overspending and ensure I can meet my needs. By making this budget program, I hope it will make it easier for me to **manage** my money and **analyze** my finances. This budget application can be **used by anyone**, but it will mostly be targeted towards *university students* who need to keep a closer watch on their finances. University students often have multiple sources of income, such as scholarships, parents' support, student loans etc. and several expenses such as tuition, housing, food,  etc., so having an app that helps them manage all that information in one place will be very useful to them.

This budget app will allow users to add multiple incomes and expenses along with information about that money such as type, amount, date, and other useful information. They will be able to calculate total money made or spent, and the app will also create graphs to help the user visualize the data. Moreover, this app will let the user explore "what-if" scenarios and see how that would impact their finances. For example, they could analyze what happens if: 
- rent increases by 5% each year,
- they decide to do summer courses and need to pay $2000 more in tuition,
- and they receive a few thousand dollars in scholarships.

This would help the user assess their financial situation and help inform them on decision making. Additionally, the app will be able to use previous weekly/monthly data and expense type to analyze trends with the user's expenses and predict future spendings, warning users what their current spending habits implies.
